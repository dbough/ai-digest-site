OpenAI's Decisions API enters public beta with new reasoning models

First reported 2026-10-06

OpenAI released its new Decisions API in public beta, featuring reasoning-capable models (GPT-6 Luna) that output structured decisions instead of text. The API charges 10 cents per million input tokens (no output token cost) and supports image inputs alongside text. The API surface is similar to competitor Jev's offering but with stronger capabilities. This represents a shift toward system-1-style fast decision-making rather than chain-of-thought reasoning.

Why it mattersDecision APIs shift the model paradigm from text generation to structured judgment, enabling cost-effective, latency-sensitive use cases (content moderation, routing, grading) while reducing hallucination risk versus generative approaches.
For buildersDevelopers can now use frontier-model reasoning for classification, routing, and judgment tasks without paying for unused output tokens, enabling new cost-effective architectures for agents and content systems.

One Thing to Explore

OpenAI Decisions API and the broader shift from generation to structured decision-making

The Decisions API represents a meaningful architectural shift: instead of using LLMs as text generators and post-processing outputs, frontier models can now directly output structured judgments (classifications, scores, yes/no) in a single forward pass. This is faster, cheaper per decision, and produces calibrated probabilities rather than text confabulation. Understanding how decision models differ from reasoning models and when to use each is becoming critical for building efficient agentic systems. The API's low input-token cost and zero output-token cost also changes the unit economics of AI-powered applications.
