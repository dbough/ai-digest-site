PyTorch's GreenLight brings AI-driven auto-approval of code reviews into open source

First reported 2026-11-27

InfoQ reports that PyTorch now lets an AI reviewer approve pull requests from its own maintainers. GreenLight is an open-source take on Meta's RADAR system, which auto-lands low-risk diffs using a risk score and an LLM review. InfoQ notes that OpenAI, Anthropic and Sonar describe similar approaches that keep humans on risky changes.

Why it mattersAutomated approval of low-risk changes is becoming a standard pattern as AI-written code outpaces human review capacity.
For buildersMaintainers of repos with high PR volume can study the risk-scoring plus LLM-review pattern as a template for gated auto-merge, with humans kept on high-risk paths.

Pros

  • Reduces review backlog for low-risk changes
  • Open-source version lets other projects adopt the pattern

Cons

  • Approval errors could slip through if risk scoring is weak
  • Reduces human scrutiny on code that is increasingly AI-written

3/5 DEVELOPER TOOLSRESEARCH

Tencent open-sources DFly2, a speculative decoder that reuses the target model's sparse KV cache

First reported 2026-11-27

Tencent has open-sourced DFly2, a speculative decoding drafter for natively sparse LLMs such as DeepSeek-V4.1-Flash, GLM-5.3-Flash and Tencent's Hy4 flash. The 0.85B-parameter, five-layer drafter keeps no KV cache of its own and reuses the target model's sparse one. MarkTechPost reports that serving tests used NVIDIA H20 GPUs with vLLM; performance figures are not fully detailed in the snippet.

Why it mattersRemoving the drafter's own KV cache targets the memory pressure that limits concurrency in long-context and agentic serving.
For buildersEngineers serving sparse models on vLLM can test whether a KV-sharing drafter improves throughput for long-context agent workloads.

Pros

  • Lower memory overhead for concurrent serving
  • Open source and tied to a vLLM setup

Cons

  • Designed for specific sparse models, so it does not generalize to all LLMs
  • Reported speedups depend on the company's own test configuration
