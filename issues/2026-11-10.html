4/5 SAFETYCODINGDEVELOPER TOOLS

Apiiro finds thousands of secrets exposed through Claude Code settings files on GitHub

First reported 2026-11-09

Security researchers at Apiiro found thousands of exposed secrets, including database passwords, API tokens, and root logins, in Claude Code settings files committed to public GitHub repositories. The cause is that choosing the 'Yes, and don't ask again' approval option stores the command approval as a rule in a local settings file, and those files can end up in version control. The coverage describes this as a partial oversight in how settings files are handled.

Why it mattersAgent tools that persist permission rules in project files can silently leak credentials into shared code, creating a new class of supply-chain and secrets risk.
For buildersAudit your repositories for committed Claude Code settings files, add them to .gitignore, and rotate any credentials that may have appeared in them.

Pros

  • Persisting approvals reduces repeated prompts for trusted commands
  • Surfacing the problem publicly helps teams fix defaults and hygiene practices

Cons

  • Thousands of exposed secrets means real-world damage is likely already done
  • Convenience features that write to project directories create hard-to-see leakage paths

Google unveils TPU 8i Max and TPU 8tx for dense inference and confidential workloads

First reported 2026-11-09

Google added two systems to its eighth-generation TPU lineup. TPU 8i Max is a dual-chip package built from two TPU 8i chips, targeting very large context windows and rack density, and MarkTechPost reports it doubles compute, SRAM, and HBM bandwidth relative to TPU 8i. Why it mattersHardware built for long-context and confidential inference affects which workloads are economical and where sensitive data can be processed.
For buildersIf you run long-context or privacy-sensitive inference on Google Cloud, these systems change capacity and latency planning, though cost and availability details are not in the coverage.
