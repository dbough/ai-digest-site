4/5 CODINGSAFETY

curl maintainer reports agent-driven Rust rewrites alongside real C-side fixes

First reported 2026-11-18

Daniel Stenberg, curl's maintainer, reports that coding agents converted about 185,000 lines of C into 340,000 lines of Rust in third-party rewrites, while the actual curl project merged over 300 commits, including roughly 200 bugfixes and several vulnerability fixes in a little over three weeks. He notes that the Rust clones do not contain those fixes and asks whether they will keep pace. This is first-hand maintainer observation, not an independent audit.

Why it mattersIt gives a concrete, practitioner-level data point on agentic coding: rewrites are cheap to generate, but maintaining the original project with agent help can deliver more tangible quality gains.
For buildersAgent throughput is real, but a rewrite's value depends on ongoing maintenance and security patching, so measure fixes landed rather than lines generated.

Pros

  • Agents enabled a large volume of verified bugfixes in the original project
  • Shows that agent-assisted maintenance of legacy C code can be productive

Cons

  • Rewrites lag behind upstream fixes, creating fragmentation risk
  • Line counts are a weak measure of quality; the evidence is one maintainer's account

3/5 MODELSCODING

Qwen3.8-27B gets a reinforcement-learned LoRA adapter for the pi coding agent

First reported 2026-11-18

Hugging Face's harness-hub team released Qwen3.8-27B-pi-adapted, a LoRA adapter trained with reinforcement learning to work inside the pi coding agent. MarkTechPost reports that coding success rose from 39% to 65% on the team's evaluation, a company-reported figure. The adapter is rank 32 and runs with vLLM or llama.cpp, letting developers swap a small harness-specific adapter onto an open base model.

Why it mattersIt demonstrates that harness-specific RL can deliver large gains on open models without retraining the base model.
For buildersIf you run local coding agents, test whether a harness-specific adapter beats prompting alone on your own tasks before adopting it.

Pros

  • Open weights and small adapter keep costs and hosting flexible
  • Large reported gain on coding success

Cons

  • Gain is measured on the publisher's own harness and benchmark
  • Tied to one agent harness, so it may not transfer
