Claude Code's 'Don't Ask Again' feature exposed developer secrets in public repositories

First reported 2026-11-22

Agentic security firm Apiiro reported that Claude Code stores approval ('Don't Ask Again') decisions in local files, and that these files and related artifacts have leaked secrets into public repositories. Apiiro says it identified 1,122 secrets in claude/settings.local.json files, plus another 1,160 in git history, the shared settings.json, and agent chat transcripts committed to repos. The finding is from a security vendor's analysis as reported by InfoQ, so the counts are the researchers' figures rather than independently verified numbers.

Why it mattersCoding agents that persist permissions and transcripts create a new class of secret-leakage risk that developers may not be checking for.
For buildersAudit any repo using coding agents for committed settings files, transcripts, and secrets, and add ignore rules or secret scanning for agent-generated config.

3/5 DEVELOPER TOOLSAGENTS

Gemini API adds Tool Retrieval so agents load tool schemas on demand

First reported 2026-11-22

Google launched Tool Retrieval in preview in the Gemini API's Interactions API. Instead of sending every tool's parameter schema in every prompt, the model loads a schema only when a task needs that tool, which targets the token cost of agents wired to dozens of functions or MCP servers. Google advises static loading for fewer than about 20 stable tools, according to MarkTechPost's summary.

Why it mattersTool definitions are a real cost and context-budget problem for large agent toolsets, and this is a first-party attempt to solve it at the API level.
For buildersIf your agent exposes many tools or MCP servers, test retrieval-based loading against static loading on both cost and tool-selection accuracy.

AWS Lambda adds GPU inference with shared models across up to 48 concurrent invocations

First reported 2026-11-22

AWS Lambda now runs event functions on EC2 G-series GPU instances through Lambda Managed Instances. Up to 48 concurrent invocations share one model per GPU, with vLLM and SGLang base images that need no handler code and 90-minute asynchronous timeouts. Billing is the instance price plus a 9.75 percent fee. Early hands-on tests reported an eight-minute publish time and no response streaming.

Why it mattersServerless GPU inference with shared model loading lowers the operational bar for deploying open-weight models on demand.
For buildersFor bursty inference workloads, compare the 9.75 percent fee and missing response streaming against always-on GPU instances before adopting.

Pros

  • Shared model per GPU across concurrent invocations can improve utilization
  • Prebuilt vLLM and SGLang images reduce setup work

Cons

  • No response streaming in early tests
  • Management fee on top of instance pricing

3/5 RESEARCHCODING

TensorLean uses Lean to formally verify GPU kernels, finding bugs in FlashAttention and DeepGEMM

First reported 2026-11-22

Researchers from Columbia University and CertiK introduced TensorLean, a Lean-based verifier that checks compiled PTX GPU kernels against tensor-level math specifications. The team checked 149 kernel instances, including every kernel of FlashAttention-2, -3, and -4 and DeepGEMM, and proved 83 correct. The remaining 66 led to 38 reported correctness bugs. These results are from the authors' own paper as summarized by MarkTechPost and have not been independently reproduced.

Why it mattersFormal verification of low-level kernels that underpin modern LLM inference and training could catch bugs that testing misses.
For buildersIf you write or rely on custom CUDA or Triton kernels, formal verification of the compiled output is a emerging option worth tracking.
marktechpost.com
