Claude Code's 'Don't Ask Again' option exposed passwords in 1,122 public GitHub files

First reported 2026-11-07

Security research firm Apiiro reports that the 'Don't Ask Again' permission setting in Claude Code, which lets the agent run commands without repeated confirmation, has coincided with secrets such as passwords appearing in 1,122 public GitHub files. The story gained substantial traction on Hacker News. The write-up is the primary source for the finding, and the scale and causal link should be checked against it directly.

Why it mattersIt shows that convenience features that reduce agent friction can quietly widen the blast radius of credential leaks in real repositories.
For buildersTreat auto-approval settings for coding agents as privileged configuration, add secret scanning to pre-commit hooks, and keep credentials out of agent-visible working directories.

3/5 CODINGDEVELOPER TOOLSAGENTS

Google open-sources Elephant-Goldfish plugin requiring coding agents to write and review specs before code

First reported 2026-11-08

Google has open-sourced the Elephant-Goldfish Model (EGM) plugin, a design-and-review layer for AI coding agents. It makes an agent write a Markdown specification before any code, then has fresh subagents with no conversation history critique that spec across review stages. Google says thousands of its engineers use it. The plugin ships with no model weights and runs on any harness that can spawn subagents, and the figures come from the MarkTechPost write-up and Google's claims.

Why it mattersIt is a concrete, open pattern for catching wrong assumptions at the spec stage, a practice that could become a standard part of agentic development workflows.
For buildersYou can adapt the spec-then-review-with-fresh-subagents pattern to your own coding agent setup without waiting for a vendor to build it in.

Pros

  • Catching wrong assumptions in a Markdown spec is much cheaper than catching them in a pull request.
  • Harness-agnostic and open, so it works with any agent that can spawn subagents.

Cons

  • Adds latency and token cost for every task, which may not pay off for small changes.
  • Google's usage claims are self-reported and there is no independent benchmark in the candidates.

3/5 MODELS

Nous Research releases Arete-27B, an open-weight Qwen fine-tune that removes state propaganda framing

First reported 2026-11-08

Nous Research released Arete-27B, a supervised fine-tune of Alibaba's Qwen3.8-27B with open weights, eval, and training data. The company reports that on its own 803-prompt eval, answers containing propaganda fell from 22% to 0.9%. These results are company-reported and the eval was built by the same lab, so independent verification is needed.

Why it mattersIt is a clear example of community and independent labs taking open-weight base models and reshaping their behavior and political framing, with full reproducibility.
For buildersThe 27B size with public weights and a 64k training context makes it a practical base for self-hosted agentic work, though the specific behavior changes should be tested against your own use case.

Pros

  • Fully open weights, eval, and training data make the claims inspectable.
  • Gives developers a self-hostable Qwen-class model with different framing defaults.

Cons

  • Eval results are company-reported on a self-built benchmark.
  • Behavior tuning around political content can be contested and could be used for unbalanced framing in either direction.
