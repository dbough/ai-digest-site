Google donates Agent Substrate and gVisor to CNCF to standardize agent security

First reported 2026-11-20

Google is donating Agent Substrate and gVisor to the Cloud Native Computing Foundation, moving two components of its agent infrastructure under vendor-neutral open-source governance, according to InfoQ. The stated goal is securing AI agents at scale. gVisor is an existing sandboxing runtime, so the donation aims to standardize isolation for agent workloads rather than introduce a wholly new technology.   • Sandboxing reduces blast radius from agents running untrusted code

  • Donation does not by itself solve authorization or identity problems for agents

3/5 DEVELOPER TOOLSAGENTS

Agent tooling launches: Gemini Tool Retrieval, AgentCore harness updates, Perplexity Orchestrator API

First reported 2026-11-19

Several infrastructure launches landed since the last briefing. Google's Gemini API added Tool Retrieval in preview, which lets agents access hundreds of tools while using fewer tokens. AWS updated Bedrock AgentCore harness to use the open-source Strands harness, adding built-in tools and lifecycle hooks for deterministic checks in the agent loop. Perplexity launched an Orchestrator API that routes requests across frontier and open-weight models with failover based on availability, capacity, and latency, billed through one account. These are incremental but concrete steps toward agent infrastructure becoming standard.

Why it mattersTool selection, deterministic hooks, and multi-model routing are becoming platform features, which lowers the cost of building reliable agents but also increases vendor lock-in risk.
For buildersTest tool retrieval against your current tool-loading approach to see whether token savings hold for your agent's tool catalog, and consider lifecycle hooks for guardrails.

Pros

  • Reducing tokens spent on tool definitions cuts cost for large tool catalogs
  • Routing and failover reduce outage exposure for production apps

Cons

  • Preview status means APIs may change before general availability
  • Routing through a single gateway concentrates dependency on that provider
