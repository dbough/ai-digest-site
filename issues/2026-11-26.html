3/5 CODINGRESEARCH

Study finds AI code reviewers need higher reasoning effort to catch plausible-but-wrong patches

First reported 2026-11-26

A new arXiv study tested Claude Opus 5.5 (preregistered) and Sonnet 5.5 and Haiku 5.5 (exploratory) as reviewers of 90 agent-written Django patches from SWE-bench Verified, at low, medium, and high effort settings. Using strengthened tests, 55 patches were found to be wrong despite passing the original benchmark tests. The paper examines how much reviewer effort is needed to catch these subtle failures, which matters as AI-written code outpaces human review.

Why it mattersAs coding agents produce code faster than humans can review it, the cost-diligence tradeoff in AI reviewers becomes a practical engineering decision.
For buildersIf you run AI code review, test whether a higher effort setting catches plausible-but-wrong patches before trusting low-cost review passes.
