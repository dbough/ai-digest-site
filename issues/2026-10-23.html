Anthropic donates Agent Skills standard to the Agentic AI Foundation

First reported 2026-10-22

Anthropic announced it is donating its Agent Skills standard to the Agentic AI Foundation (AAIF) under the Linux Foundation, the same body that already hosts the Model Context Protocol (MCP) specification. Anthropic says the goal is to keep Agent Skills open, community-driven, and vendor-neutral. Simon Willison notes he predicted the move after Anthropic first called skills an open standard last December.

Why it mattersMoving a shared agent-capability format into a neutral foundation makes it more likely to become a common cross-vendor standard rather than a single-vendor feature.
For buildersIf you build agents, Agent Skills and MCP are increasingly governed under one neutral foundation, which lowers the risk of betting on a format that only one vendor controls.

Pros

  • Vendor-neutral governance makes adoption by competing platforms more plausible
  • Consolidates MCP and Skills under one foundation, reducing fragmentation

Cons

  • Standards bodies can move slowly, and the spec may lag fast-changing practice
  • Donation does not by itself guarantee other labs will implement it

Anthropic launches OSS Scanner, a free AI vulnerability service for open-source maintainers

First reported 2026-10-23

Anthropic launched OSS Scanner, an opt-in, free service that scans enrolled open-source projects for vulnerabilities using its strongest models, including Claude Mythos. Maintainers receive periodic security reports generated without human review, and they choose whether to validate findings and which proposed fixes to accept. The service is an example of AI being pointed at defensive security work for public software.

Why it mattersFree AI-driven vulnerability discovery for widely used open-source code could meaningfully shift how maintainers keep up with security issues.
For buildersIf you maintain or depend on open-source libraries, enrolling in scanner programs like this may surface issues faster, but you will need a process for triaging unreviewed AI reports.

Pros

  • Gives under-resourced maintainers access to strong security analysis at no cost
  • Opt-in design keeps maintainers in control of fixes

Cons

  • Reports generated without human review may include false positives or noise
  • Maintainers may face triage burden from high volumes of automated findings

Harvard study finds AI coding tools raise code volume but not completed work

First reported 2026-10-22

A Harvard study of 718 firms, using Jellyfish analytics data, found that AI coding assistants and agents increase code volume without a matching increase in completed work. The study attributes part of the gap to downstream bottlenecks, especially code review, which absorbs the extra workload that AI-generated code creates.

Why it mattersIt challenges the assumption that faster code generation automatically speeds delivery, shifting attention to review and integration capacity.
For buildersIf you adopt coding agents, measure end-to-end throughput, including review and merge time, rather than lines or commits produced.

Google Cloud unveils Agent Compute Engine with a hardware-isolated microVM per agent

First reported 2026-10-23

Google Cloud announced Agent Compute Engine, a compute service built for AI agents that gives each agent session its own hardware-isolated microVM with a separate guest kernel and root access. The sandboxes hold no credentials by default. Google says the service already powers Gemini as an agent for work tasks, and a customer preview is targeted for the coming months.

Why it mattersPurpose-built isolation for agents addresses one of the central security and scaling problems in deploying autonomous agents.
For buildersIf you run agent workloads that execute code, per-session microVMs may become a safer default than shared containers, though the preview is not yet available.

Pros

  • Hardware isolation reduces the blast radius of misbehaving agents
  • Zero-credential sandboxes limit exposure of secrets

Cons

  • Only a future customer preview, so availability and pricing are unknown
  • Ties agent infrastructure more tightly to Google Cloud
