The LLM-based system writes executable tests designed to fail on a risky code change, giving concrete evidence that a diff altered behavior. Meta reports that JiTTests caught 74 privacy SEVs at the diff stage in the first half of 2026; this figure is company-reported and comes via a secondary summary, with the method described in an FSE 2026 paper.

3/5 AGENTSSAFETYENTERPRISE

Uber publishes a framework for governing autonomous AI agents across their lifecycle

First reported 2026-11-15

Uber Engineering describes a Secure AI Framework that decides whether an agent's action is appropriate, given the user's request, the agent's intended purpose, its permissions, and the interaction context. The authors argue that traditional identity and API controls are insufficient for agents that reason over external content and take real-world actions. The framework is designed to govern agents across their full lifecycle.

Why it mattersIt is a practical enterprise pattern for controlling agent actions beyond static permissions, a gap many organizations face as agents gain real-world reach.
For buildersConsider adding per-action appropriateness checks that combine user intent, agent purpose, and permissions, rather than relying only on API scopes.

Pros

  • Addresses real limits of identity and API controls for autonomous agents
  • Offers a concrete, production-oriented pattern from a large engineering organization

Cons

  • Effectiveness of contextual action judgments depends on the judging model's reliability
  • Adds latency and complexity to agent workflows

3/5 RESEARCHSAFETYBUSINESS

Research shows API relays can silently swap models mid-conversation, undermining audits

First reported 2026-11-16

An arXiv paper finds that the fingerprint a classifier uses to identify the LLM behind a text is contagious: a model that continues a conversation begun by another model inherits that model's fingerprint. This means API relays could serve early turns from the model a customer pays for and hand later turns to a cheaper model. Detection accuracy for the substitute drops from 0.97 to 0.72 in one reported case (DeepSeek replacing Claude Sonnet).

Why it mattersIt exposes a practical trust gap in model marketplaces and resellers, where customers cannot easily verify which model answered.
For buildersIf you use third-party API relays, consider logging model identifiers and running spot checks, since per-turn audits may miss handoffs.

Pros

  • Highlights a real verification gap that could push for better provenance guarantees
  • Gives auditors a concrete failure mode to test

Cons

  • Detection results are from a specific classifier and model pair, so generality is uncertain
  • Limited to text-classifier-based detection in the candidates
