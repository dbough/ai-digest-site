AWS adds KV-cache-aware routing and managed NVIDIA Dynamo for LLM inference

First reported 2026-11-17

Amazon SageMaker AI real-time endpoints now support KV cache-aware routing, which sends requests to instances already holding a long cached match for the prompt, unless those instances are too busy. SageMaker HyperPod Inference also now supports NVIDIA Dynamo for distributed inference, separating prompt processing from token generation to serve very large models. Both are AWS product announcements describing configuration steps and tradeoffs.

Why it mattersCache-aware routing and disaggregated serving can substantially reduce latency and cost for multi-turn and long-prompt workloads at scale.

  • Managed Dynamo reduces operational burden for very large models

  • Adds configuration and operational complexity tied to AWS

3/5 RESEARCHMODELS

Research shows language models can improve themselves by rewriting their own weights

First reported 2026-11-18

An arXiv paper reports that a 27B model, given its own weights, graded answers, and the ability to run itself, can diagnose its failures and edit its own weights to improve, with no gradients and no training. The authors call this self-rewriting. It is a preprint and the results have not been independently replicated, but the approach would be a notable new mechanism if it holds up.

Why it mattersIf models can reliably self-edit without gradient training, post-deployment improvement could move from separate training runs into the inference loop.
For buildersTreat this as a research direction to watch; it may eventually change how you think about fine-tuning versus prompt and scaffold improvements.

External sandboxes for coding agents

Simon Willison and Prime Radiant describe a pattern where the agent lives outside the sandbox while the code it executes runs inside a dedicated one, which limits damage from mistakes or prompt injection, especially when using local models.
