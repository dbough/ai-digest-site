Google launches Gemini Decisions API with Gemini Decision 1

First reported 2026-11-11 · Latest update 2026-11-12

Google launched the Gemini Decisions API, powered by Gemini Decision 1, a model that does not generate text. It scores up to 1,000 typed questions (yes/no, choice, rubric scoring) against one shared input and returns calibrated probabilities, with a 256K-token shared context. Google prices it at $0.10 per million input tokens with output free; Latent Space reports roughly 200ms end-to-end latency, and those performance figures are company-reported. It arrives in a category that OpenAI's GPT-6 Luna and the Jev model from TypeSafe AI already occupy, which is why it's being framed as a new "system one" model class.

Why it mattersIt establishes non-generative, structured decision models as a product category, giving agent builders a cheap, fast alternative to calling a full reasoning LLM for routing and policy checks.
For buildersUse it for the small branching calls inside agents, such as tool selection, routing, guardrails, and grading, where a calibrated probability is more useful than a generated answer.

Pros

  • Much cheaper and faster than reasoning LLMs for narrow classification-style calls
  • Calibrated probabilities make thresholds and fallbacks easier to design

Cons

  • Performance and latency numbers are company-reported so far
  • Google-hosted only, and it's a new API that teams will have to evaluate against OpenAI and Jev alternatives

4/5 MODELSRESEARCH

Google DeepMind releases AlphaGenome 2 for cell-type-specific DNA variant effects

First reported 2026-11-11

Google DeepMind released AlphaGenome 2, a conditional sequence-to-function model that reads a 1 Mb DNA window plus a target cell state to predict variant effects in specific cell types. Its predecessor averaged across bulk tissues, while this version distinguishes closely related cell types and adapts to unseen single-cell datasets without fine-tuning. It is available through an API for non-commercial research, and the performance claims come from DeepMind's own reporting.

Why it mattersCell-type resolution moves genomic prediction closer to the biological context where disease mechanisms actually operate, which could speed hypothesis generation for drug targets.
For buildersResearchers and bioinformatics teams can test it through the hosted API, though the non-commercial license limits production use.

Pros

  • Cell-type-specific predictions are more biologically precise than bulk-tissue averages
  • Works on unseen single-cell datasets without fine-tuning

Cons

  • Predictions still need experimental validation before clinical use
  • API is non-commercial and hosted only for now

United Airlines blocks unauthorized AI agents from booking flights

First reported 2026-11-11

United Airlines said it will not let personal AI assistants book tickets on its site, citing privacy, unintended purchases, and regulatory concerns. According to The Wall Street Journal (via The Verge), the airline has not yet seen many customers try to book through agents, though it is concerned that agents could expose information or skirt federal requirements for passenger information. The policy was widely discussed on Hacker News.

Why it mattersIt is an early example of a major consumer company explicitly gating third-party agents, which could make agent access to commerce a negotiated, permissioned channel rather than open web automation.
For buildersIf you're building agents that act on external websites, plan for sites that block or restrict automated booking, and design for official partner APIs where they exist.

Pros

  • Protects customers from agents making purchases they didn't intend
  • Helps the airline meet passenger-information and security obligations

Cons

  • Could push agent commerce toward closed partner channels and limit consumer choice
  • Blanket bans may frustrate users who want assistive tools and accessibility-driven automation

3/5 DEVELOPER TOOLSCODING

AWS releases official open-source local emulator for its services, built largely by agents

First reported 2026-11-11

AWS published aws-emulator, an official tool for running tests against a local clone of many AWS services without a paid cloud account. It is written in Rust and was built by a large number of coding agents, with 29,684 commits in the first three weeks according to Simon Willison, citing a guest post by Swami Sivasubramanian on Werner Vogels' blog. It currently requires Docker on macOS and Windows, which Willison notes is a limitation.

Why it mattersIt is a notable real-world case of agent-written infrastructure software from a major cloud provider, and it lowers the cost of testing cloud-dependent code.
For buildersTry it in CI for AWS-dependent test suites to avoid paid API keys and speed up local iteration, but note the Docker requirement on non-Linux systems.

Pros

  • Free local testing reduces cloud costs and speeds up test loops
  • Official status means it is more likely to track AWS API changes

Cons

  • Docker dependency on macOS and Windows adds setup friction
  • Agent-written codebases raise open questions about long-term maintainability and review depth
